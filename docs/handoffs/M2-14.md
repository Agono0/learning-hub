## What was built

- **Foreground service (specialUse, targetSdk 37)**: persistent "Max Focus
  active" notification (IMPORTANCE_LOW channel, ongoing); anchors the session
  to `SystemClock.elapsedRealtime()` (monotonic, sleep-inclusive — the same
  tamper-resistant clock contract as the core machine's monoAnchor,
  M2-01/M2-20) via `KEY_START_ELAPSED_REALTIME` in the shared prefs;
  `sessionElapsed` returns `{ elapsedRealtimeMs, deviceElapsedRealtimeMs }`.
- **Boot resume**: `MaxFocusBootReceiver` on BOOT_COMPLETED relaunches the app
  when `KEY_RESUME_EXPECTED` is set (set by the plugin at session start,
  cleared at end). Device Owner apps are exempt from Android 10+'s
  background-activity-start restriction, so the launch works from the
  receiver; the actual re-apply (lock windows, Lock Task, watcher) belongs to
  the session flow (M2-24), this receiver only surfaces the app.
- **Anti-uninstall**: hard gate = `dpm.setUninstallBlocked(admin, package,
true)` (Device Owner only, via `focus_android_set_anti_uninstall`); the
  non-owner path gets an honest disable-warning dialog
  (`onDisableRequested`). The ALWAYS-restored guarantee: the release path
  pairs set/unset, and M2-24's boot reconcile re-asserts the state.
- **lib.rs commands** (registered unconditionally; desktop errors cleanly):
  `focus_android_session_service(active)`, `focus_android_session_elapsed`,
  `focus_android_set_anti_uninstall(enabled)`.
