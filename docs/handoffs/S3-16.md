## What was delivered

Ten runtime-neutral handlers under `apps/web/src/server/handlers/tasks/` (+
`_shared.ts`, not a route), each mirrored by an `app/api/tasks/**` shim and
registered in `src/hub/handlers-registry.ts`:

| Route                       | Methods            | Behavior                                                                                                                                                                                                                             |
| --------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `/api/tasks`                | GET, POST          | list (query scopes `projectId=all\|inbox\|<id>`, `parentId=all\|top\|<id>`, `includeDone`, `includeWontdo`, `limit`; defaults = SP list semantics: open top-level tasks in display order) / create from core `createTaskInputSchema` |
| `/api/tasks/[id]`           | GET, PATCH, DELETE | read / validated `updateTaskInputSchema` patch / delete with `?via=` and a S3-12 trash entry returned (`{ deleted, trash }`)                                                                                                         |
| `/api/tasks/[id]/complete`  | POST               | completes; parent completion sweeps open subtasks; won't-do → 400 `wontdo-cannot-complete`                                                                                                                                           |
| `/api/tasks/[id]/reopen`    | POST               | reopen / un-won't-do; clears archive tier                                                                                                                                                                                            |
| `/api/tasks/[id]/duplicate` | POST               | `(copy)` + subtasks + tag links (201)                                                                                                                                                                                                |
| `/api/tasks/[id]/archive`   | POST               | `{ tier: young\|old, archivedAt? }` upsert                                                                                                                                                                                           |
| `/api/tasks/[id]/restore`   | POST               | removes the tier row (404 when not archived)                                                                                                                                                                                         |
| `/api/tasks/[id]/tags`      | PUT                | wholesale tag-set replacement (400 on unknown ids, previous set untouched)                                                                                                                                                           |
| `/api/tasks/bulk`           | POST               | `{ ids, op }` via core `bulkOpSchema` → `{ applied, skipped }`; unknown ids `{ id, reason: 'not found' }`                                                                                                                            |
| `/api/tasks/order`          | POST               | `{ ids }` dense renumber OR `{ id, targetIndex, listIds }` single drag (echoes the new order)                                                                                                                                        |
