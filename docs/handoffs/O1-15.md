## Component contract

`UpdateBanner({ offer, onApply?, onDismiss?, applying? })` — pure
presentation, no fetch, no effects, SSR-safe (`renderToString` = hydrated
markup):

- **Play gate:** renders nothing when `SELF_UPDATE_ENABLED === false` (baked
  `LH_UPDATE_CHANNEL=play`) — the store gate cannot be flipped at runtime
  because the constant is import-time.
- **Calm by default:** `offer === null` renders nothing; a fresh offer shows
  one primary action ("Download update"), one demoted ghost ("Not now").
- **Ask-first copy:** always states "installs after you restart — nothing
  changes until then". The button hands off to the update service (download →
  inactive slot → apply on restart); `applying` shows the loading state
  (`aria-busy`, "Preparing…") and disables "Not now".
- **Honest sizes:** `Hot update · <patch KB> · full download <full MB>` when a
  patch matches; `Full download · <size>` otherwise; `app reinstall required`
  appended when `requiresNative`. `formatUpdateSize` (exported, tested) formats
  B/KB/MB with calm numerals and survives junk input.
- **Boundaries:** notes render as escaped text (React default — tested with a
  `<script>` payload, never `dangerouslySetInnerHTML`); no raw fetch; kit-first
  (`Button` with 44px coarse-pointer targets, focus-visible via global styles).
