  fixed-row windowing — pure `windowRange` (startIndex/endIndex/offsetY/
  totalHeight from scrollTop, clamped, overscan-aware) + a one-listener

  documented); content truncates per row.

  ≥ 50 items (`WINDOW_THRESHOLD`); below it plain rendering — zero visual
  change for the common case. Sectioned lists stay plain (small by
  construction).
