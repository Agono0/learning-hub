## What was built

- **`MaxFocusReportCard`** — the quiet post-session report for endings the
  user did not choose: `timer` ("Session complete — you stayed for the full N
  minutes") and `battery` ("ended early — low battery… progress is saved").
  User exits (`pin`) never show a card — the exit flow is the closure. Calm
  by law: no confetti (that is the session-complete moment), one dismiss
  action (icon button ≥44px on coarse pointers + a "Done" ghost).
- **Two feed paths, one presentation point**:
  1. native bridge event `max-focus://released` (M2-23, dynamic tauri import,
     haptics pattern) — `{ reason, sessionId }`;
  2. window CustomEvent `lh:max-focus-report` (pinned name) with a
     `MaxFocusReportData` detail — for web hosts and the future M2-04 session
     handler (its exit endpoint can dispatch the event with real timestamps).
     `reportDurationMinutes` derives whole minutes defensively (negative/NaN →
     null → generic copy).
