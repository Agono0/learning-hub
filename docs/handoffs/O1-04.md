# O1-04 — Custom URI-scheme protocol serving the active slot

`lib.rs` registers the `lhslot` scheme: `serve_slot_protocol` resolves the
request path via `update::lookup_in_active_slot` (added to update.rs + tested:
promoted files served, missing/unsafe → None) and falls back to the bundled
asset resolver, 404 otherwise. MIME map for the `.next-tauri` export; empty
path → index.html. Capabilities need NO rebinding (they bind by window label
and custom schemes are app origins) — analysis documented in code +
docs/updates.md §"Slots & the webview origin", which also flags the
origin-change OPFS/localStorage scope risk for the lead (rule 10 adjacency,
needs storage migration decision before first promotion). Compiles in CI once
the O1-02 Cargo.toml request lands (rule 17).
