## Core

`packages/core/src/tasks/focus-modes.ts` — the three SP strategies as a pure
machine over wall-clock phases (the same drift-free model as the focus
timer; the timer glue owns ticks):

- **pomodoro** — 25/5 with the long break every 4th run
  (`long_break_start` event); `advanceFocusMode(state, nowMs)` is
  idempotent per instant and rolls phases forward automatically.
- **flowtime** — open-ended focus; the user stops the run
  (`completeFocusRunEarly`) and the earned break = elapsed × 20%
  (floored at the configured minimum). Stopping outside a focus phase
  throws.
- **countdown** — one fixed block; `cancelFocusMode(state, nowMs)` resets
  runs/phases but KEEPS the strategy + task binding.
- **S3-80**: `countdownMinutesFor(task, today, min=5)` — the countdown
  default is the task's REMAINING estimate (estimate − tracked today),
  floored at 5, null without an estimate.
- **S3-34 (binding half)**: the state carries `taskId` on every
  transition, so the timer glue logs ticks `source: 'focus'` against the
  bound task; a Max Focus session started from a task binds the same way.
  The idle-suppression half of S3-34 lands with S3-33.

## UI

`apps/web/src/components/tasks/FocusModePicker.tsx` — the three strategy
chips (aria-pressed) wired into the focus page's standard tab; applying a
strategy sets the page timer's minutes; countdown surfaces the remaining-
estimate default honestly (with a task bound) or explains the manual length
(without). `strategyFocusMinutes` exported for tests.
