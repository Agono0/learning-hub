## What it does

`node scripts/update-manifest.mjs --dir <export> --out <manifest.json> ...` (full usage in the
file header):

1. Recursively hashes the `.next-tauri` export → `files[]` sorted by path, forward-slash
   paths, lowercase-hex sha256 + byte size (streaming hash, empty dir is a hard error).
2. Builds the manifest: `manifestVersion: 1`, channel (default `nightly`), version,
   `buildSha` (7–40), `createdAt` (RFC 3339, overridable for deterministic CI),
   `minNativeVersion`, `requiresNative` (flag, default false), `fullPackageUrl` (https only).
3. Delta patch set vs up to 5 previous manifests (`--prev`, newest first → O1-19 chain):
   each patch bundle is a zip (`fflate`, already a workspace dep) containing ONLY
   added/changed files at their export-relative paths; patch entries carry
   `{ fromVersion, url, sha256, size }` where `url = patch-base + patch-<from>-<to>.zip`
   (base derived from `--full-package-url` directory or `--patch-base-url`).
4. Writes `manifest.json` (2-space JSON + newline) and the patch zips next to `--out`,
   prints a human summary (file count, KB, per-patch KB — feeds O1-20's patch-size notes).
5. The manifest is written unsigned; signing is the separate CI step (O1-08/O1-09).

## API surface (exported, importable for tests/CI reuse)

`hashTree(dir)`, `diffManifests(prevManifest, nextFiles)`, `buildPatchBundle(dir, changed)`
(path-traversal guarded), `sha256Hex(bytes)`, `derivePatchBaseUrl(fullPackageUrl)`,
`generateManifest(options)` (pure: returns `{ manifest, patchArtifacts }`),
`writeOutputs(outPath, result)`, `parseArgs(argv)` (kebab flags, `=value`, repeated
`--prev`, `--requires-native` boolean forms; throws loudly on missing/invalid),
`main(argv)`, `MAX_PATCHES = 5`.

Types for TS consumers live in `scripts/update-manifest.d.mts` (shape mirrors core's
`UpdateManifest`/`UpdatePatch`/`UpdateFile` without pulling zod into the script).

## Test list (`packages/core/tests/update-manifest-script.test.ts`)

- `hashTree`: nested hashing matches `node:crypto` digests, sorted paths, sizes; empty dir throws.
- `generateManifest`: fresh export → schema-valid (validated against core's
  `updateManifestSchema`), no patches; patch bundle vs changed previous export contains only
  changed+added files with NEW contents (verified by unzipping) and not unchanged ones;
  patch url/sha256/size consistency; 5-patch cap with newest-first selection out of 7 prevs;
  determinism for identical input; rejects http URL / unknown channel / empty dir.
- `buildPatchBundle`: throws on `../` path escape (hostile prev manifest).
- `diffManifests`: flags added+changed, ignores deletions.
- `parseArgs`: kebab/`=`/repeat/boolean parsing; throws on missing required, bad sha, http
  url, unknown channel/flag, http patch base.
- `main` end-to-end: writes manifest.json + `patch-...zip`; on-disk JSON equals returned
  manifest and re-parses through the core schema; zip digest matches `patches[0].sha256`.
