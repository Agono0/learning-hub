# M2-20 — Tamper detection (clock + permissions)

Clock-change detection already lives in `advanceSession` (monotonic anchor vs
wall-clock divergence → ended with reason `tamper`, terminal). This task adds
the permission half to `packages/core/src/focus-lock/session.ts`:
`missingRequiredPermissions(granted, required)` (case-insensitive, trimmed) and
`tamperFrictionReason(missing)` (human-readable friction_events payload:
"permissions revoked: …" / "clock tamper: …"). Tests: classification,
friction reasons, and the mid-session revoke → `forceUnlockSession(...,
'tamper')` → terminal flow. The platform bridges (Rust/Kotlin, M2-23/M2-14)
poll permissions and call the force-unlock; handlers log the reason into
`friction_events` (append-only, rule 8) when wiring M2-04.
