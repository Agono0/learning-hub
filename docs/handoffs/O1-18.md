# O1-18 — Tamper rejection tests

Tamper matrix completed in `apps/native/src-tauri/src/update.rs` tests:
modified manifest rejected at signature level
(`rejects_tampered_manifest`), wrong key rejected
(`rejects_wrong_public_key`), bad/malformed sha256 rejected
(`verifies_and_rejects_file_hashes`), modified file during slot download
rejected before disk write (`download_rejects_tampered_file_and_keeps_
pointer`), and NEW: corrupted pointer (torn write / unknown slot / wrong
type / empty) rejected at parse — with the design note that pointers are
origin-trusted (native-written) while signature trust lives in the manifest.
