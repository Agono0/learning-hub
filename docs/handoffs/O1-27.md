Worker: W3 · Branch: `feature/mega-run` · Files:

## What was built

- **`useUpdateDownloadProgress()`** (`platform/update-progress.ts`): subscribes
  to the Rust downloader's `update://download-progress` events (O1-16 emits
  `{ downloaded, total }` from `update_download_file`); null off-Tauri, never
  throws, cleaned up on unmount. `progressRatio()` derives the 0..1 bar value
  defensively (negative/NaN/zero-total → 0, over-100 → 1).
- **`UpdateBanner`** gained an optional `progress` prop: while `applying` AND
  a reading exists, the kit `ProgressBar` renders under the size line
  (role=progressbar, aria-valuenow). Without a reading the banner keeps the
  plain "Preparing…" state — no fake bars.

## Test list (apps/web/tests/update-progress.test.ts)

- ratio clamping + junk inputs (negative, zero-total, NaN, null);
- banner renders `role="progressbar"` + aria-valuenow="50" at 50% while
  applying; no bar without a reading or while not applying;
- hook export contract (off-Tauri no-op).

## Wiring

The mounting surface (Settings > Updates / the shell banner mount, O1-14/O1-25)
calls `useUpdateDownloadProgress()` once and passes the reading into
`<UpdateBanner progress={...} applying={...} />`.
