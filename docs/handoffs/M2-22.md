# M2-22 — Allowlist editor UI

**Status:** done. **Branch:** `feature/mega-run`. **Worker:** W2.

## Component

`apps/web/src/components/MaxFocusAllowlistEditor.tsx` — rendered in the focus
page's Max Focus configurator (below the main panel, above the extension
bridge card). Full CRUD over `/api/focus/allowlists` (GET list, POST create,
PUT `/:id`, DELETE `/:id` — existing handlers, no API changes):

- preset list with domain/app counts and the default marker;
- quiet per-row delete (`IconButton`, aria-labelled) and an Edit affordance;
- edit draft: rename (`TextField`), domain chips add/remove, desktop-app
  chips add/remove, "Use as the default preset" `Toggle` (the repo enforces
  a single default), one `Save preset` primary action + `Done`;
- create flow: one name input + `Create`, which selects the new preset for
  immediate editing;
- copy states the key invariant: **a preset is frozen into the session at
  start — edits apply to future sessions only** (matches the repo's
  allowSnapshot semantics).

Errors surface inline (`role="alert"`), never silent.

## Wiring

`apps/web/app/focus/page.tsx` — `<MaxFocusAllowlistEditor />` in the
configurator branch. The per-session extras inputs remain (they are the
per-session overlay; presets are the reusable base).
