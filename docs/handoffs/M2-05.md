# M2-05 — Topmost fullscreen lock windows across all monitors

New `apps/native/src-tauri/src/lock_win.rs` built on TAURI's own window APIs
(zero new Cargo deps — deliberately not raw Win32): one borderless,
always-on-top, fullscreen webview per `available_monitors()` entry loading the
bundled shell (M2-16/M2-18 render checklist + exit gate inside). Idempotent
apply/release (stale windows closed first — M2-24 crash-resume path),
`is_locked()` for the M2-23 status command, `covers_monitor()` math for
M2-07's refocus loop. Unit tests: prefix-rule round-trips + coverage math
(incl. left-of-primary monitor). `mod lock_win;` registered in lib.rs.
