  allowlist is authored without suffixes).

  names; empty allowlist allows nothing (lock window only).
- **`should_refocus(process, is_lock_window, allowed_apps)`** — the M2-07

  foreign window refocuses; **Task Manager ALWAYS triggers** (it can never be
  allowlisted into legitimacy — M2-08 disables it entirely). `needs_refocus`
  now delegates with an empty allowlist (back-compat, same behavior).

  `apply_lock_windows_with_allowlist(app, &[])` — M2-23's session commands
  pass `FocusLockPayload.apps` (the session allowlist from the web layer) and
  it flows into the refocus loop thread (normalized once, moved in).
  `release_lock_windows` unchanged.
