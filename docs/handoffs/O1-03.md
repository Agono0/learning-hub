# O1-03 — A/B update slots (app_data_dir)

Extended `apps/native/src-tauri/src/update.rs` with the A/B slot machinery:
`SlotId`/`SlotPointer` contracts, `read_pointer` (missing file → slot A default),
`write_pointer_atomic` (tmp + rename; `std::fs::rename` replaces on Windows),
`inactive_slot` targeting, `download_to_inactive_slot` (clears the inactive
slot, hash+size-verifies every file BEFORE writing it, refuses traversal paths,
stores the signed manifest verbatim — never touches the pointer),
`promote_inactive_slot` (explicit atomic flip), and `list_current`
(active/inactive + installed versions). File fetching is an injectable closure;
production passes `fetch_file_bytes` (https-only, no capacity hint from
manifest sizes). Tests in `slot_tests` cover default/flip, fill+status,
tamper/size/path rejection, and tmp-file cleanliness — all network-free via
temp dirs. Compiles in CI once the O1-02 Cargo.toml request lands.
