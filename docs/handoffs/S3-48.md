## Component

`apps/web/src/components/tasks/TaskRemindersDialog.tsx` — kit `Sheet` over
`/api/tasks-reminders`:

- **List** — existing reminders for the task (GET `?taskId=`): `at_time`
  rows show their clock moment (`YYYY-MM-DD HH:MM`), `relative` rows show a
  human offset label (`offsetLabel`, exported: presets named verbatim,
  arbitrary offsets rounded to `45 min before` / `2h after` / `1h 30m
  after`); `exactAlarm` rows carry an `exact` tag.
- **Add** — kind switch: `at_time` (datetime-local input) or `relative`
  (offset presets from the S3-08 planner's window: at due, −15m, −1h, −3h,
  −1d, +10m); `exactAlarm` toggle (Android exact-alarm path,
  `supportsExactAlarms` copy). `validateReminderForm` (exported) mirrors
  the handler boundary; errors surface inline.
- **Remove** — quiet per-row `IconButton` → DELETE `/api/tasks-reminders/[id]`.
- **Global policy section** — the master `remindersEnabled` toggle + quiet
  hours summary, read/written through the single settings PUT (`/api/settings`)
  so per-task reminders and the global policy live in one place; the M2-21
  settings lock guard applies upstream automatically (423 while a Max Focus
  session runs).

All writes invalidate `['tasks-reminders', taskId]` + `['settings']`.
