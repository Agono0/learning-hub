## Architecture

- **Proxy handler** `GET /api/update/notes?channel=nightly|beta|stable`: the ONE
  network hop to the channel pointer (`channel-pointers` release,
  `LH_UPDATE_POINTER_BASE` env overridable, 10s timeout). The pointer is
  untrusted input — validated through core `parseUpdatePointer` (O1-28):
  unknown fields stripped, invalid → `{ notes: null, reason: 'pointer-invalid' }`,
  unreachable → `{ notes: null, reason: 'pointer-unavailable' }`. Never 500s the
  UI for an informational feature. Unknown channels → 400 (zod, before any fetch).
  UI never fetches cross-origin (rule 1 — everything via `apiGet`).
- **Lib** `fetchChannelNotes(channel)` in updates.ts: maps the proxy reply to
  `ChannelNotes | null` (version-only pointers yield `notes: null`, not an error).
- **UI** `UpdateChangelog` mounted in Settings > Updates (hidden for Play
  builds — the store listing is their changelog). Honest states: skeleton
  while loading, calm "No changelog published for this channel right now"
  for empty/unavailable, notes rendered via `<Markdown>` (untrusted-content
  law — no raw HTML), version + localized publish date line above.
  Refetches when the picker changes the channel.
