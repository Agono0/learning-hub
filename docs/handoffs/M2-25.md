# M2-25 — Max Focus session history UI

**Status:** done. **Branch:** `feature/mega-run`. **Worker:** W2.

## Component

`apps/web/src/components/MaxFocusSessionHistory.tsx` — presentation-only
section fed by `GET /api/focus/max/history` (M2-04):

- **Sessions** — task label, start time, planned/actual minutes, enforcement
  tier, and a status `Badge` per row:
  - running sessions get a pulsing accent "running" badge (`endedAt === null`);
  - ended sessions show their persisted `exitReason` through
    `EXIT_REASON_LABELS` (the M2-01 unlock-reason union: timer / pin /
    battery / failure / tamper) with one hue per meaning via
    `EXIT_REASON_TONES` (timer = success; pin/battery = warning;
    failure/tamper = danger).
- **Exit reflections** — the append-only friction log entries (rule 8)
  listed under the sessions with date + reflection text.

Honest states: skeleton while loading, `Callout` on error, `EmptyState`
("No Max Focus sessions yet") when empty.

## Wiring

`apps/web/app/focus/page.tsx` — rendered in its own `Reveal` section between
the shared session-history panel and the distraction apps panel (the shared
panel keeps showing ALL sessions incl. standard pomodoros).
