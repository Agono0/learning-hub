## What was built

- **Kotlin**: `MaxDeviceAdminReceiver` (the dpm target — declared with
  `BIND_DEVICE_ADMIN` + `@xml/max_device_admin` force-lock policy set) and
  `MaxFocusAndroidPlugin` (`@TauriPlugin`, `deviceOwnerStatus` →
  `{ packageName, isDeviceOwner, isLockTaskPermitted }` — the lock-task flag
  is M2-11's hook, same plugin). Provisioning itself CANNOT run from the app:
  `dpm set-device-owner` requires ADB + an account-free device — by design.
- **Rust bridge** (lib.rs): `max-focus-android` plugin registration (same
  pattern as O1-13) + the `focus_android_provision_status` command
  (registered unconditionally; desktop answers "Android-only").
- **Web**: `platform/device-owner.ts` —
  `DEVICE_OWNER_ADB_COMMAND` (the exact, test-pinned string),
  `deviceOwnerProvisioningSupported()`, `deviceOwnerStatus()` (null off-Android /
  on failure — the wizard shows "unknown", never a false "provisioned").
- **Focus page** (`DeviceOwnerPanel`, mounted in the Max Focus area,
  hydration-safe mount detection): shows the verbatim ADB command in a
  selectable code row, copy button with confirm-in-place "Copied", and the
  live provisioned state. Android+Tauri only; calm, honest copy ("enabling
  device admin alone grants nothing").
