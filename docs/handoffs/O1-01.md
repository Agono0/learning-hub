## What this is

The zod contract + pure helpers every other OTA task (O1-02…O1-28) consumes.
Header JSDoc cites the architecture: content-addressed manifest over the
`.next-tauri` export, Ed25519 minisign signatures (verify never disabled, native
layer O1-02), A/B slots (O1-03/05), `nightly.json` pointer on GitHub Releases,
channels `nightly|beta|stable`, Play builds gate self-update off at the client
service layer (O1-12) — not here.

## API surface (`@learning-hub/core/update`, also re-exported from the barrel)

| Export                                    | Kind        | Notes                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `updateChannelSchema` / `UpdateChannel`   | schema/type | `nightly \| beta \| stable`                                                                                                                                                                                                                                                                                                                             |
| `platformSchema` / `UpdatePlatform`       | schema/type | `windows-x86_64`, `android-arm64-v8a`, `android-armeabi-v7a`, `android-x86_64`, `android-universal`                                                                                                                                                                                                                                                     |
| `updateFileSchema` / `UpdateFile`         | schema/type | `{ path, sha256 (64 lowercase hex), size (int > 0) }`                                                                                                                                                                                                                                                                                                   |
| `updatePatchSchema` / `UpdatePatch`       | schema/type | `{ fromVersion, url (https), sha256, size }`                                                                                                                                                                                                                                                                                                            |
| `updateManifestSchema` / `UpdateManifest` | schema/type | `manifestVersion: literal(1)`, channel, version, `buildSha` (7–40), `createdAt` (RFC 3339, offsets OK), `minNativeVersion`, `requiresNative`, `files` (≥1), `patches` (≤5), `fullPackageUrl` (https)                                                                                                                                                    |
| `updatePointerSchema` / `UpdatePointer`   | schema/type | `{ channel, version, manifestUrl (https), publishedAt (RFC 3339), notes? }` — this is `nightly.json`                                                                                                                                                                                                                                                    |
| `latestJsonSchema` / `LatestJson`         | schema/type | Tauri official-updater shape `{ version, notes, pub_date, platforms: Record<string, { url, signature }> }` (Windows native layer, O1-10)                                                                                                                                                                                                                |
| `updateSettingsSchema` / `UpdateSettings` | schema/type | `{ channel = 'nightly', autoCheckIntervalHours = 6 (1–168), wifiOnly = true, autoApply = literal(false) (ask-first locked), lastCheckedAt? }` — consumed by Settings (O1-14)                                                                                                                                                                            |
| `assertHttps(url)`                        | fn          | `true` iff absolute `https://`; every URL field refines through it                                                                                                                                                                                                                                                                                      |
| `compareVersions(a, b)`                   | fn          | `-1 \| 0 \| 1`; numeric dot segments (missing = 0), semver §11 prereleases (`beta.1 < rc.1 < release`), build metadata ignored; **nightly tags `nightly-YYYYMMDD-<sha>` parse to base `YYYYMMDD` + sha suffix and sort AFTER their bare base**; `nightly-`/`v` prefixes and case tolerated; huge numerics compared length-then-lex (no precision flips) |
| `pickPatch(manifest, fromVersion)`        | fn          | first patch with `compareVersions(p.fromVersion, fromVersion) === 0`, else `null` = fall back to `fullPackageUrl`                                                                                                                                                                                                                                       |

Unknown keys are stripped (zod default) so pointer validation is forward-compatible
(O1-28 relies on this).

## Test list (`packages/core/tests/update.test.ts`)

- manifest: valid accept; bad sha256 (uppercase / short / non-hex); http URL in
  `fullPackageUrl` and patch `url`; unknown channel; empty `files`; 6 patches
  rejected / 5 accepted; wrong `manifestVersion`; missing fields; bad `createdAt`;
  short `buildSha`; JSON round-trip parse equality.
- pointer: valid accept, `notes` optional, http `manifestUrl` rejected, unknown
  channel rejected.
- latest.json: Tauri shape accepted; http artifact URL + missing `platforms` rejected.
- settings: defaults from `{}`; `autoApply: true` rejected; interval bounds 0/169/168.
- `platformSchema`: known keys accepted, foreign keys rejected.
- `assertHttps`: https true; http/ftp/relative/garbage/empty false.
- `compareVersions`: numeric order; `1.2 == 1.2.0`; prerelease chain; nightly tag
  after base; `nightly-` prefix invariance; date-then-sha ordering; nightly above
  old release numbers; metadata/prefix/case tolerance; garbage input; full
  antisymmetry matrix over 8 representative versions.
- `pickPatch`: exact match; tag-variant match; null fallback.
