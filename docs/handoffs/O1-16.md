# O1-16 — Resumable ranged download + progress events

update.rs: `RangeResponse` (206 Partial / 200 Full), `range_header`,
`resume_offset`, `progress_percent`, `RangeFetcher` seam (unit-injectable),
`fetch_range_http` (https-only, status captured before body read),
`download_resumable` (resumes at file size, scratches stale partials larger
than total, size+sha verified in full, progress callback fires at start and
end), `download_resumable_http`. lib.rs: `update_download_file` command —
dest must live under `<app_data_dir>/updates` (webview cannot target
arbitrary paths) — emitting `update://download-progress`
(`{downloaded,total}`) for the banner (O1-15/O1-27 glue point). Tests:
range math, resume/restart/full-response, stale-partial scratch, size and
final-hash rejection. Compiles in CI once the O1-02 Cargo request lands.
