## What was delivered

Seven runtime-neutral handlers + shims + registry entries:

| Route                       | Methods | Behavior                                                                                                                                                                                                   |
| --------------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/api/tasks-time/tick`      | POST    | `{ taskId, sessionMs, startedAt?, source? }` — appends one session (append-only log) and re-derives the task's per-day map; junk ticks → `{ skipped: true }`; done/won't-do task → 400; missing task → 404 |
| `/api/tasks-time/stop`      | POST    | flushes the final buffer (optional `sessionMs`) and always returns the server-derived map (client never computes time truth)                                                                               |
| `/api/tasks-time`           | GET     | `?taskId=&day=&from=&to=` — session history + filtered totalMs                                                                                                                                             |
| `/api/tasks-time/[id]`      | DELETE  | S3-28 inline correction: removes one erroneous row and recomputes the task map (404 when missing)                                                                                                          |
| `/api/tasks-worklog`        | GET     | `?from=&to=` (default last 7 days) — `{ totalMs, perDay[], perTask[] }` rollups from the log                                                                                                               |
| `/api/tasks-worklog/export` | GET     | RFC 4180 CSV (`task_id,title,day,minutes,source,started_at`), `text/csv` attachment                                                                                                                        |
| `/api/tasks-finish-day`     | POST    | `{ day? }` (default today) — S3-29 data pass: `completedThatDay`, `trackedMs`, `stillOpenForDay`, and the applied S3-11 auto-archive pass result                                                           |
