# M2-06 handoff — Windows low-level keyboard hooks (session-scoped)

Worker: W3 · Branch: `feature/mega-run` · Files: `apps/native/src-tauri/src/lock_win.rs`
(`should_swallow_key` + `key_hooks` module + lifecycle wiring + tests). Dep: M2-05.

## What was built

- **Pure decision function** `should_swallow_key(vk, alt_down, ctrl_down, win_key)`:
  swallows exactly the locked-decision escapes — **Win, Alt+Tab, Alt+F4,
  Ctrl+Esc** — everything else passes (plain Alt, plain Esc, Ctrl+Tab, typing,
  the emergency dialer's keys). Plain-const VKs so the logic tests without the
  windows crate.
- **`key_hooks` module** (cfg(windows)): a dedicated thread installs a
  `WH_KEYBOARD_LL` hook via `SetWindowsHookExW` and pumps messages; the proc
  touches only atomics (a slow LL hook is silently dropped by Windows —
  LowLevelHooksTimeout). Ctrl state is tracked from VK_CONTROL down/up events
  (the KBDLLHOOKSTRUCT carries no Ctrl flag); Alt comes from `LLKHF_ALTDOWN`.
  Removal posts `WM_QUIT` so `UnhookWindowsHookEx` runs on the installing
  thread. `install()` is idempotent and waits ≤5s for the hook thread's ready
  signal; `remove()` deactivates first (a fail-open bias), then quits + joins.
- **Session scoping:** `apply_lock_windows` installs, `release_lock_windows`
  removes — the suppression can never outlive the lock windows, and a crashed
  session converges clean on the next apply (M2-24 resume path).
  `key_hooks::active()` is exported for M2-23 status reporting.
- API patterns verified against the local cargo registry sources
  (windows-0.62.2: `SetWindowsHookExW(WINDOWS_HOOK_ID, HOOKPROC, Option<HINSTANCE>, u32)`,
  `KBDLLHOOKSTRUCT_FLAGS::contains`, `PostThreadMessageW`, `GetCurrentThreadId`
  in the already-enabled Win32_System_Threading feature) — no Cargo.toml
  changes needed.

## Tests (in-module `#[cfg(test)]`, run by CI's cargo test)

- `hook_swallows_exactly_the_session_escape_keys`: all four escapes swallowed;
  near-misses pass (plain keys, Ctrl+Tab, Alt+Esc, half-combos); Win flag
  dominates.
- existing label/coverage tests untouched and still passing by inspection.

## Docs

Module header carries the design law (scope, fail-open bias, never-block
proc, thread-pump architecture); fold a user-facing summary into
docs/max-focus.md when M2-28 lands. The hook suppresses OS-shell escapes only
— it is not a keylogger: nothing is recorded, only a swallow decision.
