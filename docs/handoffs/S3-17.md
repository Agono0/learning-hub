## What was delivered

Eleven runtime-neutral handlers + shims + registry entries:

| Route                                | Methods            | Behavior                                                                                      |
| ------------------------------------ | ------------------ | --------------------------------------------------------------------------------------------- |
| `/api/tasks-projects`                | GET, POST          | list all rows (backlog + archived) / create `{ title, notes?, backlogFlag?, color? }`         |
| `/api/tasks-projects/[id]`           | GET, PATCH, DELETE | read / patch / **delete = tasks move to inbox** (SP semantics; history untouched)             |
| `/api/tasks-projects/[id]/archive`   | POST               | idempotent shelving (`archivedAt` stamped)                                                    |
| `/api/tasks-projects/[id]/restore`   | POST               | trophy reopen (S3-75)                                                                         |
| `/api/tasks-projects/[id]/duplicate` | POST               | copies project + OPEN tasks (+ subtasks/tag links); archived source → 400                     |
| `/api/tasks-tags`                    | GET, POST          | list / create (normalized name; duplicate → 409)                                              |
| `/api/tasks-tags/[id]`               | PATCH, DELETE      | rename/recolor (clash → 409) / unlinks every task then deletes                                |
| `/api/tasks-sections`                | GET, POST          | list in display order / create (`sortOrder` defaults to end)                                  |
| `/api/tasks-sections/[id]`           | PATCH, DELETE      | rename/reorder / delete                                                                       |
| `/api/tasks-views`                   | GET, POST          | user views (built-in Kanban/Eisenhower live in core, no row) / create with rule-chip `filter` |
| `/api/tasks-views/[id]`              | PATCH, DELETE      | update / delete                                                                               |
