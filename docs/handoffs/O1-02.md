# O1-02 — Rust update module skeleton

Added `apps/native/src-tauri/src/update.rs` mirroring W3's
`packages/core/src/update/index.ts` contracts: `UpdatePointer`/`UpdateManifest`
serde shapes (camelCase), https-only fetch via blocking `ureq` (30s timeout,
`LazyLock` agent), minisign (Ed25519) signature verification, and sha256
per-file verification with lowercase-hex guards. Unit tests use a generated
known-key fixture (real Ed25519 signature over exact manifest bytes, tamper +
wrong-key + malformed-hash rejections). Registered `mod update;` in lib.rs.
`Cargo.toml` deps (`minisign-verify 0.2`, `sha2 0.10`, `ureq 2` tls-only) are a
LEAD request in docs/SHARED_CHANGES.md (supersedes the pre-claim draft — no
hex crate needed, plugin-http's async-only re-export unusable for blocking
fetch). Compiles in CI once the request lands (rule 17: no local builds).
