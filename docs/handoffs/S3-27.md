# S3-27 — Calendar import: iCal feed subscription + CalDAV VTODO read

## Core — `packages/core/src/ics.ts` (additive; writer untouched)

- `parseCalendarFeed(text)` — total RFC 5545 reader (never throws): unfolds
  §3.1 continuations (CRLF/LF), quoted params (`TZID="…:…"`), nested
  components skipped via a nesting counter (a VALARM's DESCRIPTION can never
  masquerade as the event's), TEXT unescaping, STATUS lowercasing. Stamps
  normalize: `VALUE=DATE`/compact → `YYYY-MM-DD` + `allDay`, UTC → ISO `Z`,
  floating → naive ISO. Malformed props are dropped, events missing UID or
  DTSTART are discarded, junk documents → `{events:[],todos:[]}` (zod at the
  boundary: `calendarFeedEventSchema` / `calendarFeedTodoSchema`).
  RRULE is intentionally NOT expanded — the master event imports once;
  expansion belongs to the planner's clock, not a text parser.
- `extractVCalendarSegments(text)` — pulls `BEGIN:VCALENDAR…END:VCALENDAR`
  spans out of WebDAV multistatus XML (XML-entity-unescaped first) for the
  CalDAV path; `parseCalendarResponseBody(text)` = segments + parse merged.

## Handler — `apps/web/src/server/handlers/calendar/import/route.ts`

`POST` (registered as `calendar/import` + shim `app/api/calendar/import`):
zod body `{ url: https-only URL ≤2048, kind: ical|caldav }`; the handler is
the one network hop (rule 1), 15 s timeout, honest 502 on unreachable/non-ok
feeds, junk feeds resolve to empty collections. No persistence server-side —
see the client store.

## Client — `apps/web/src/lib/calendar-feeds.ts` (device-local)

Subscription list + per-feed snapshot cache in localStorage
(`lh-calendar-subscriptions` / `lh-calendar-feed-cache`), zod-validated at
every read (corrupted → empty, never a crash): add/remove/update,
visibility + color fields (S3-83's future hook), `putFeedCache` stamps
`lastImportedAt`. Device-local by design (audit L7a family, like
`@/lib/updates`): a subscription controls THIS device's planner; a server
home would be a LEAD schema batch (not requested — this is honest scope).

## UI — `apps/web/src/components/CalendarSubscriptions.tsx` + planner mount

Self-contained `<section id="calendar-subscriptions">` mounted on the
planner page (one import + one JSX line — minimal diff vs W1's planner
work): add form (name / https URL / iCal|CalDAV), per-sub refresh with
loading state, honest error copy, per-sub visibility toggle, next-events
preview from the cache (offline-safe). Hydration-safe: all storage reads
are effect-only (state-driven cache, not render-time reads). Kit-first:
SectionHeader/TextField/Button/Toggle/EmptyState/Badge; no banned classes;
no fetch in UI (apiSend).
