# O1-19 — Upgrade-from-N patch chain

update.rs gains `apply_patch_bundle(base, installed, target, manifest_bytes,
patch_bytes)`: clears the inactive slot (deletions ride on the clear), copies
UNCHANGED files (same path+sha+size) zero-bandwidth from the active slot,
unpacks the O1-07 zip patch verifying every entry against the TARGET manifest
(path must be listed; size+sha256 must match) before writing, and hard-errors
when any target file has no source — a truncated bundle can never yield a
half-updated slot. Tests build real zips via the zip crate and walk a
5-manifest chain (v1 full install → v2 modify → v3 modify+add → v4 modify +
DELETE → v5 modify+add), asserting exact slot content, slot alternation and
final `list_current` version; plus smuggled-file and truncated-patch
rejections. Cargo request: `zip = 2` (deflate only) filed in
docs/SHARED_CHANGES.md. Compiles in CI once the O1-02/O1-19 requests land.
