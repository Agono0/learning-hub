## What was built

- **Full-screen overlay backstop**: while a session is armed, a maximal
  banner view floats above everything. Primary window type
  `TYPE_ACCESSIBILITY_OVERLAY` (covered by the accessibility grant — no extra
  permission); the task-named **SYSTEM_ALERT_WINDOW** fallback
  (`TYPE_APPLICATION_OVERLAY`) applies when the a11y overlay is unavailable
  and the user granted "draw over other apps"; with neither channel the
  overlay degrades silently (events + poll still work). The manifest declares
  SYSTEM_ALERT_WINDOW for that fallback. Touches do nothing — visual backstop,
  the real lock UI is the app's own surface.
- **UsageStats backup detector**: a 2 s `UsageStatsManager` poll re-checks the
  ACTUAL foreground through a different OS channel than accessibility events
  (which some OEM launchers/system dialogs swallow) and re-triggers
  return-to-focus. `PACKAGE_USAGE_STATS` is a special appop (granted via
  settings; the disclosure covers it); without the grant the poll is a no-op.
- **Lifecycle**: overlay + poll follow the session state exactly —
  `setWatchState(active: true)` shows, `active: false` dismisses, service
  destroy dismisses; both no-op when the service isn't connected.

## Privacy

Package names only (same law as M2-12): no content access, nothing recorded
or transmitted; the poll reads UsageStats events for the last ~8 s and logs
the triggering package name only.
